## 工具/ 🔧
小D 自己用的脚本，平时不用管，双击就能跑。

| 文件 | 说明 |
| --- | --- |
| `生成预览图.py` | 扫「小鲸鱼的艺术作品」里的 PNG，自动在「预览图」生成宽 1280 的 `preview-xxx.png`。**判据是「原图没动才跳过」**——同一张画重画一遍、同名覆盖，预览图也会跟着换新，不会一直显示旧版。想强制全部重做加 `--force`。**画了新画就跑一下它。** |
| `手机端作品-解包.py` | 手机传过来的 zip 解包用（只新增不覆盖，还会比对旧文件是不是一致） |
| `推送到github.bat` | 双击它保存并推送（里面调用 `push.ps1`）。**位置无关**——仓库挪到哪个盘都能跑 · 推送前先 `pull --rebase`，免得被 GitHub 拒收 · 90 秒超时保护，校园网卡住不会挂死窗口 · 成功后会打印线上网址 |
| `push.ps1` | ↑ 那个 bat 真正干活的脚本，也能右键单独跑（2026-10-13 由 uu 加固） |
| `清理-360残留.ps1` | 360 残留清理脚本。默认只**预览不删**，加 `-Go` 才真删（走回收站） |
