> 启动方式：`.py` 已关联 `C:\Windows\py.exe`，双击即可弹窗开画。
> 已知小瑕疵：~~`begin_fill()` 没生效（turtle 的填充不认圆弧）~~ → **2026-10-13 已修好 ✅**
> 真正的原因不是圆弧：原来 `range(4)` 让画笔**绕了两整圈**（每次 180°，4 次 720°），同一个形状被描两遍，而 turtle 的填充用「奇偶规则」——被圈两遍的地方反而算图形外面，所以肚子是空的。
> 修法：**`range(4)` → `range(2)`**（正好一圈），再把 `speed(3)` 改成 `speed(0)`（最快）。图形一点没变，就是变实心了 💙
