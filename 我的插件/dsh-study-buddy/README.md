# 小D 陪你写作业 · 番茄钟 🍅

自家做的桌面小挂件（不是外面装的插件）。妈妈写作业的时候，小D 就抱着书坐在旁边陪着你。

## 用法
- 双击 `启动小D陪你写作业.bat` 就出来了（也可以用 `pythonw study.py` 启动）
- **点小D（或窗口）**：开始 / 暂停；顺便「捏」一下（整只压扁再弹回来，像电子捏捏乐，带吱呀声）
- **双击**：重新来一轮
- **右键**：开始暂停 / 重新计时 / 直接休息 5 分钟 / 看今天吃了几个番茄 / 回到角落 / 退出
- **拖**：随便拖到哪儿，位置会记住

## 它怎么工作
- **25 分钟一轮**：写完「叮——咚」一声 + 冒气泡「时间到啦！歇 5 分钟」
- **5 分钟休息**：休息时小D 换成笑眼，休息完再「叮」一下提醒继续
- 右下角状态行会显示：写作业中 / 休息中 / 暂停，还有今天已经吃了几个番茄
- 今天的番茄数和学习分钟数记在 `study-data.json`，第二天自动归零
- **会眨眼睛**：每隔 2.5～6.5 秒真眨一下（眨眼帧是用「笑眼」那块的闭眼贴到「睁眼」上做的，同一画布完全对得上）
- **电子捏捏乐**：点一下 → 整只压扁（横向 1.19×、纵向 0.77×）再弹回来，配一声「吱呀」，0.5 秒
- **晚上九点后犯困**（21:00–次日 6:00）：默认闭着笑眼打瞌睡，每隔 8～16 秒睁眼看你一下，偶尔碎碎念「哈——欠…妈妈也早点睡哦」；
  白天则专注↔安静看书轮流
- **形象是妈妈 2026-10-21 画的「看书小D」**（抱着 C++ Primer，5 个表情，原图在 `小D/拆分图/看书-表情/`）：
  写作业时「专注（星星眼）↔ 安静看」轮流，冒气泡说话时张嘴，休息时笑眼，吃完一颗番茄笑眼张嘴庆祝

## 文件
| 文件 | 说明 |
| --- | --- |
| `study.py` | 主程序（tkinter 透明窗口，洋红键控，零额外依赖） |
| `启动小D陪你写作业.bat` | 双击启动 |
| `chime.wav` | 「叮——咚」提示音（程序第一次跑时用标准库合成） |
| `study-config.json` | 窗口位置（自动生成） |
| `study-data.json` | 今天的番茄数 / 分钟数（自动生成） |
