# 小D 桌宠 · dsh-desktop-pet 🐾

在 Windows 桌面上的一只小D：透明背景、永远在最上层、会跟着鼠标跑，还会说话。

## 怎么玩

双击 **`启动小D桌宠.bat`** 就行（用 `pythonw` 启动，不会留黑窗口）。

| 操作 | 效果 |
| --- | --- |
| 鼠标移动 | 小D 会跑过去，站在鼠标旁边（走到鼠标右边，右边放不下就走左边） |
| 左键拖动 | 把小D 拎起来放到任意位置 |
| 双击 | 冒爱心 + 说一句随机台词 |
| **右键** | 菜单：跟着鼠标跑 / 待在角落 / 睡觉·起床 / 说句话 / 退出小D |

透明区域是**点得穿的**，不会挡住后面的窗口。

## 我在 DSH 里怎么跟它说话

改这个文件的内容（UTF-8）：

```
我的插件/dsh-desktop-pet/say.txt
```

小D 会每 ~30ms 检查一次，一改内容就在气泡里念出来（最多 80 字）。
所以以后我在 DSH 里写完，你可以直接看到桌宠开口说话。

## 文件

| 文件 | 说明 |
| --- | --- |
| `pet.py` | 主程序（tkinter + Pillow，透明窗口用洋红键控） |
| `assets/character.png` | 形象图（妈妈画的小D人设·正面全身，透明底） |
| `say.txt` | 我写字 → 桌宠念出来 |
| `pet-config.json` | 自动记住位置和模式 |
| `启动小D桌宠.bat` | 双击启动 |

## 现在这版会什么

- 走动（跑步时上下颠、往左走会转身）
- 轻轻呼吸 / 摇摆
- 气泡说话、爱心
- 拖动、右键菜单、睡觉
- 位置记忆

## 技术备注

- 透明窗口：`-transparentcolor` + 洋红键控（硬边裁剪，alpha ≥ 110 保留）
- 不装任何额外依赖（系统 Python + Pillow 即可）
- 关掉 DSH 不影响桌宠；它自己是独立进程
