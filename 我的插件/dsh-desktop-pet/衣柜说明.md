# 小D 的小衣柜 · 换装说明

桌宠右键 → **「换装 👗」** 就能换衣服啦。晚上 21:00–06:00 会自动换上睡衣，早上换回当天的衣服（菜单里也有开关）。

## 自动换装（2026-10-25 起）

| 什么时候 | 穿什么 |
|---|---|
| 工作日 · 春（3–5 月） | **初雪水手服** |
| 工作日 · 夏 / 秋（6–11 月） | **白大褂**（值班小D） |
| 工作日 · 冬（12–2 月） | **雪日冬装**（画好了才有；没有就先穿白大褂） |
| 周六、周日 | **格雷系千金**（妈妈说最用心的那套） |
| `holidays.txt` 里写的日子（节假日 / 生日 / 纪念日） | **格雷系千金** |
| 晚上 21:00 – 早上 06:00 | **睡衣** |

- 季节按月份自动算，不用手动设；想试别的季节可以设 `PET_FORCE_SEASON=spring|summer|autumn|winter` 再开桌宠

- **妈妈今天手动挑过衣服 → 这一天就听妈妈的**，第二天自动恢复规矩
- 右键「换装 👗」里有开关：`晚上 21:00 自动换睡衣（开/关）`、`周末/节假日穿千金（开/关）`
- 节假日清单在同目录 **`holidays.txt`**：一行一个 `MM-DD`（每年都算）或 `YYYY-MM-DD`（只算这一年）；`!` 开头表示这天反过来算上班（调休补班的周末用）；改完不用重启
- 小提示：现在里面只写了 `10-12 小D 的生日`，2027 的放假安排出来再往里加就行

## 妈妈画了新衣服之后怎么加进来

妈妈只要画 **三个表情**（按顺序）：

1. **睁眼**（平时站着的样子）
2. **闭眼笑**（被摸头、开心时）
3. **猫嘴 ω**（卖萌时）

然后小D 用一条命令就能做成新衣服：

```
python 工具\生成换装素材.py 白大褂 睁眼.png 闭眼笑.png 猫嘴.png
```

生成的帧会放进 `我的插件/dsh-desktop-pet/outfits/白大褂/`，右键菜单里就会多出「白大褂」这一项。

### 如果某张表情多画了一点小装饰（2026-10-25 加）

同一套衣服里，如果有一张多了个星星/闪光之类的小装饰，**逐张自动裁边会让每张宽度不一样**，
眨眼时角色会左右跳几像素。这时给一个统一的裁切框（整套衣服的并集 bbox）：

```
python 工具\生成换装素材.py 观星夜斗篷 睁眼.png 闭眼笑.png 猫嘴.png --box 85,91,881,1275
```

`--box x0,y0,x1,y1` 是原图上的裁切框（用「所有表情的 alpha 并集」算出来最稳）。

## 帧的命名规则（如果手动放文件的话）

```
outfits\<衣服名>\idle_<尾巴角0-3>_0.png    睁眼
outfits\<衣服名>\blink_<尾巴角0-3>_0.png   闭眼笑
outfits\<衣服名>\wink_<尾巴角0-3>_0.png    猫嘴 / 单眼眨
```

- 尾巴角 4 个值：0 / 1 / 2 / 3（-6.5° / -2.2° / +2.2° / +6.5°），现在暂时四张一样也能跑
- 缺某个表情时会自动借「常服」的那张，所以先画一张也能先挂上看看
- 图片建议：透明底 PNG，整只角色、高度越大越清晰（会自动缩到 340px 高）
