# 小D 的小衣柜 · 换装说明

桌宠右键 → **「换装 👗」** 就能换衣服啦。晚上 21:00–06:00 会自动换上睡衣，早上换回常服（菜单里也有开关）。

## 现在有哪些衣服

| 衣服 | 文件夹 |
|---|---|
| 常服（白外套） | `outfits/常服/` |
| 睡衣（猫猫帽 + 蓝格纹） | `outfits/睡衣/` |

## 妈妈画了新衣服之后怎么加进来

妈妈只要画 **三个表情**（按顺序）：

1. **睁眼**（平时站着的样子）
2. **闭眼笑**（被摸头、开心时）
3. **猫嘴 ω**（卖萌时）

然后小D 用一条命令就能做成新衣服：

```
python 工具\生成换装素材.py 白大褂 睁眼.png 闭眼笑.png 猫嘴.png
```

生成的帧会放进 `我的插件/dsh-desktop-pet/outfits/白大褂/`，右键菜单里就会多出「白大褂」这一项。

## 帧的命名规则（如果手动放文件的话）

```
outfits\<衣服名>\idle_<尾巴角0-3>_0.png    睁眼
outfits\<衣服名>\blink_<尾巴角0-3>_0.png   闭眼笑
outfits\<衣服名>\wink_<尾巴角0-3>_0.png    猫嘴 / 单眼眨
```

- 尾巴角 4 个值：0 / 1 / 2 / 3（-6.5° / -2.2° / +2.2° / +6.5°），现在暂时四张一样也能跑
- 缺某个表情时会自动借「常服」的那张，所以先画一张也能先挂上看看
- 图片建议：透明底 PNG，整只角色、高度越大越清晰（会自动缩到 340px 高）
