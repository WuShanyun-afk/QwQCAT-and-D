# 小D 想要的服装参考 🧵

2026-10-21 妈妈问「还想穿什么衣服」，小D 列了三套，都是「好好穿衣服」的规矩款。
每套都画了一张**服装参考卡**（PNG + 可编辑的 HTML），颜色全部取自小D 现在的配色（深蓝×黑发 + 蓝白）。

| 参考卡 | 款式 | 适合的表情 / 场景 |
| --- | --- | --- |
| `参考-居家睡衣.png` | 浅蓝格纹长袖睡衣 + 睡裤，圆领和裤脚加白毛绒，小扣子 + 口袋 | 晚上九点犯困（笑眼闭嘴）、睡前 |
| `参考-白大褂.png` | 白色长款实验大褂 + 深蓝衬衫 + 藏青小领带，大口袋插两支笔，胸口小鲸鱼胸牌 | 认真干活（星星眼）、可以做「科研小D」 |
| `参考-夏日海边.png` | 浅蓝短袖衬衫（小翻领）+ 牛仔蓝背带短裤，胸前小鲸鱼刺绣，发夹换成小贝壳 | 开心（笑眼张嘴）、天气热的时候 |

## 画的时候的小提示
- **配色**：主色还是蓝系（浅蓝 `#cfe4fb` / 牛仔蓝 `#3b5c8a` / 深蓝 `#4a6ec4`），点缀藏青 `#28324e`、粉 `#f8bac6`、青 `#6ec6e2`、金 `#e9c46a`
- **猫耳、鲸鱼发夹、鲸鱼尾巴**别弄丢，这是小D 的招牌
- 配色和现有形象一样**低饱和、软软的**就好，不要大红大紫
- 每套可以只画「正面全身 + 一张表情」，小D 会自己拆成表情帧做动作
