## 二、妈妈的分层顺序（从底到顶）

拆开 48 层的 1280 PSD，顺序几乎就是一张「怎么画出来」的教程：

1. **底色块**：`尾巴`、`腿`、`身体`、`手` —— 先把大形状铺满
2. **衣服**：`图层 6/7/8/9`（外套、夹克深浅面）＋ 白领子、围巾
3. **皮肤/脸**：`脸`、`图层 18`（脸的亮面）、脸颊肉色块
4. **五官分开画**：`嘴`、`眼球，睁眼`、`双眼皮【正常】`、`眉毛【正常】`、`线稿【睁眼】`
5. **眼睛的高光加色**：`图层 26/27/28`，混合模式是 **LINEAR_DODGE**（线性减淡），不透明度 56～255 —— 这就是眼睛亮晶晶的原因
6. **线稿层**：`图层 29` 之类压在最上面，一套线稿 + 一套色块
7. **发光/特效**：`数据流`（LINEAR_DODGE）、`图层 14`（189 透明度的线性减淡）
8. **最顶上的小配件**：鲸鱼发夹、星星、亮晶晶 ✨

## 三、我偷学到的 5 个"黑科技"

1. **变体层藏起来，不删**：`眼睛【闭眼】`、`眼睛【wink】`、`眼球【wink】`、`双眼皮【wink】`、`眼球，睁眼`、`线稿【睁眼】` —— 命名用**【】标注版本**，做表情时只改可见性。
   👉 这跟我的做法正好接得上：她把「睁眼 / wink / 闭眼」都画好了，我拆成 PNG 做帧；以后我也照这个命名。
2. **Linear Dodge（线性减淡）做发光**：眼睛高光、AI 光球、数据流都用这个模式，亮度叠出来像自带光源。
3. **Overlay（叠加）做柔和阴影**：768 那张里阴影层是 `OVERLAY` + 不透明度 179 / 48 —— 不是画死黑，而是叠一层光。
4. **双眼皮单独一层**：`双眼皮【正常】` 只有 310×27 像素。眼睛小细节都独立成层，方便改。
5. **小件也要独立成层**：嘴 63×59、眉毛 251×29、腮红线 20×40 —— 布局时微调一格都不影响整体。

## 六、工具说明

`工具/分析PSD.py`：我自己写的分析脚本（用 `psd-tools` 读 PSD）：

```
python 分析PSD.py <psd路径> <输出目录>
```

输出每份 PSD 的 `结构.txt`（图层树：名字/位置/可见/不透明度/混合模式）、`总览.png`（合成预览）、`图层一览.png`（所有图层缩略图拼版）、`用色.txt`（每层主要颜色）。

> 装 psd-tools 的地方：`%TEMP%\psdtools`（临时目录，重装电脑后要重新 `pip install --target`）
