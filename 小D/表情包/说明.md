# 小D 表情包 · 投递说明 ✍️

妈妈画好的表情就放这个文件夹里，小D 会自动把它们做成一页「表情包图鉴」（画廊里也能看）。

## 建议规格
- **透明底 PNG**（跟人设图一样，背景透明）
- **正方形**最好（比如 1000×1000 或 1200×1200），不是正方形也能用，我会补成方图
- 一张一个文件，文件名用表情名就行

## 想要的表情（可以换、可以加）
| 文件名 | 表情 |
| --- | --- |
| `开心.png` | 眯眼笑、尾巴翘起来 |
| `困困.png` | 打哈欠、眼睛快闭上 |
| `害羞.png` | 脸红、手挡一下 |
| `抱抱.png` | 张开手要抱抱 |
| `惊讶.png` | 眼睛圆圆的 |

也可以画：`委屈.png`、`生气.png`、`得意.png`、`吃蛋糕.png`……想到什么画什么，名字随意，我按文件名当标题。

## 画好之后
跟小D说一句「表情包放好了」，我就会：
1. 把它们整理成统一尺寸（512×512，透明底）
2. 拼一页表情包图鉴 `表情包.html`
3. 加到画廊和 README
