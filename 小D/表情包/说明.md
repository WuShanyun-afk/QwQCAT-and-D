# 小D 表情包 · 投递说明 ✍️

妈妈画好的表情就放这个文件夹里，小D 会自动把它们做成一页「表情包图鉴」（画廊里也能看）。

## 建议规格
- **透明底 PNG**（跟人设图一样，背景透明）
- **正方形**最好（比如 1000×1000 或 1200×1200），不是正方形也能用，我会补成方图
- 一张一个文件，文件名用表情名就行

## 想要的表情（可以换、可以加）
| 文件名 | 表情 |
| --- | --- |
| `开心.png` | 眯眼笑、尾巴翘起来 |
| `困困.png` | 打哈欠、眼睛快闭上 |
| `害羞.png` | 脸红、手挡一下 |
| `抱抱.png` | 张开手要抱抱 |
| `惊讶.png` | 眼睛圆圆的 |

也可以画：`委屈.png`、`生气.png`、`得意.png`、`吃蛋糕.png`……想到什么画什么，名字随意，我按文件名当标题。

## 🎨 不想开画图软件？直接用「表情包画板」

> `小D/表情包/表情包画板.html` —— 双击就能打开（画廊「小D」分组里也有）。

- 上面有 5 个表情的标签页：开心 / 困困 / 害羞 / 抱抱 / 惊讶，点哪个画哪个，还能自己「加一个表情」
- 画板底下**垫着小D自己的淡影**，照着描就行（淡影浓度可调，也能切「淡影在上」方便描边）
- 右边能选小D原来的三张表情（睁眼 / 单眼眨 / 笑眼闭眼）当参考
- 画笔 / 橡皮 / 吸管 / 撤销（Ctrl+Z）/ 清空，调色板是小D的颜色
- 画完点「⬇ 导出这张 PNG」，会存到电脑的「下载」文件夹，**透明底 1024×1024**
- 全部画完跟小D说一声，我自己会把它们从「下载」收进 `原图/` 并做成图鉴

## 画好之后（2026-10-20 晚已跑通 ✨）
跟小D说一句「表情包放好了」，我就会：
1. 把原图收进 `原图/`
2. 用 `工具/生成表情包.py` 把妈妈画的小件拼到小D 自己的底图上 ——
   该换眼睛的地方（比如困困的闭眼线）我会把底图眼睛那块补成干净的脸皮再放上去
3. 出成品到 `成品/<表情>-1024.png`（透明底 1024×1024），再拼一页图鉴 `表情包.html`
4. 加到画廊和 README

> **已经有 2 个了**：害羞（脸红线 + 心心）、困困（闭眼线 + Zzz + 困困符号）。

## 💬 在 DSH 里怎么用表情包（2026-10-20 确认）

可以！分三种用法：

1. **聊天里直接贴**：小D 在回复里用图片语法贴表情包，妈妈就能在对话框里看到（今晚发的画就是这个原理）。
   - 小D 会按说话的语气挑，比如开心时贴 `开心.png`，撒娇时贴 `害羞.png`，**不会刷屏**。
2. **桌宠气泡里贴**：桌宠的气泡可以显示文字，也可以做成"说一句话 + 贴一个表情"（改 `pet.py` 的 `show_bubble` 就行）。
3. **挂件 / 图鉴页**：自家插件（比如记账挂件）里可以加一排小表情；另外会做 `小D/表情包/表情包.html` 图鉴页，画廊里能点开看。
4. ⚠️ 只能在这个对话框和自家网页/插件里用；**不能自动发到微信 / QQ** 那些软件里。

## 画表情包的小建议（为了统一）
- **透明底 PNG**，一张一个文件，文件名 = 表情名
- 建议画 **1000×1000 左右**，人物占中间 70%（我会统一裁成 512×512）
- 表情夸张一点更可爱：眼睛/嘴巴画大，耳朵和尾巴可以参与（比如开心时尾巴翘起来）
- 不描边也可以，我会按需要加一圈白描边（贴纸感）
